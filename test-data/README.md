Тестовые данные: 10 случайных ников и паролей.

- `accounts.sql` — самостоятельный SQL-скрипт создания таблицы AUTH и вставки записей.
- `accounts.tsv` — пары ник/пароль.
- `limboauth-test.db` — отдельная SQLite-база, созданная импортом accounts.sql.

Это вручную подготовленная схема по RegisteredPlayer, а не дамп, созданный
запущенным плагином. Рабочая база сервера не изменялась.

Проверка: `python3 test-data/verify.py`. Скрипт импортирует SQL во временную базу,
повторно открывает её и проверяет 10 паролей, уникальность ключа и целостность.
Это проверка SQL-данных, а не Java-обработчика входа.

Компиляция плагина была запущена с JDK 17, но остановилась при загрузке
зависимостей: DNS для maven.elytrium.net и repo.opencollab.dev недоступен.
Компиляция, Checkstyle и вход через Minecraft не подтверждены.

Сам плагин создаёт таблицу через ORMLite без постоянного SQL-файла.
По умолчанию H2 хранится в каталоге данных плагина как limboauth-v2.mv.db;
при выборе SQLite используется limboauth.db.
